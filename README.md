# 🛒 QuiClick — E-Commerce Storefront

[![Shopify](https://img.shields.io/badge/Platform-Shopify-green?style=flat&logo=shopify)](https://shopify.com)
[![Status](https://img.shields.io/badge/Status-Active-brightgreen)](#)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**QuiClick** es una plataforma de comercio electrónico diseñada para ofrecer una experiencia de compra rápida, intuitiva y optimizada para conversión en el mercado colombiano, con soporte integrado para pagos contra entrega (COD).

---

## ⚡ Características Principales

- 📱 **Diseño Responsive & Mobile-First:** Experiencia fluida adaptada a cualquier dispositivo.
- 🚚 **Integración COD (Cash on Delivery):** Optimización de checkout enfocada en pago contra entrega para el mercado local.
- 📦 **Dropshipping Sync:** Configuración optimizada para sincronización y gestión de inventario con proveedores (Dropi).
- 🎨 **UI/UX Personalizada:** Secciones dinámicas, diseño limpio y enfoque en rendimiento de carga.
- 📊 **Tracking & Analítica:** Preparado para integración con píxeles de seguimiento (Meta Pixel, Google Analytics) para optimización de campañas.

---

## 🛠️ Tecnologías Utilizadas

- **Plataforma:** Shopify
- **Frontend / Templating:** Liquid, HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
- **Integraciones / Logística:** Dropi Colombia
